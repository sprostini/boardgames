Backup & data

Your collection and play log live in this browser. Download a backup regularly so nothing is lost if the browser is cleared.

Push your collection to a Google Sheet (with cover images) as a cloud copy, and pull it back to restore anywhere. Show one-time setup ▾

  1. Open sheets.new to make a blank Google Sheet.
  2. Extensions → Apps Script.
  3. Delete any code, paste everything from google-apps-script.gs (in your boardgames folder), click Save.
  4. Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone, then Deploy.
  5. Authorise: pick your account → Advanced → “Go to … (unsafe)” → Allow. (It’s your own script.)
  6. Copy the Web app URL and paste it below → Save URL.
